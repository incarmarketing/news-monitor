# 본문 밖 제목으로 발생한 부정 경보 보정

## 확인 범위

2026-10-07~2026-10-13 KST 신규 수집 776건 중 부정 41건, 경보 대상
37건의 합집합인 42건을 점검했다. 부정 알림 성공 기록은 43건이었다.
이는 전체 누적 기사 정확도 추정치가 아니라 해당 기간의 경보 점검 결과다.

원문 42건을 읽어 실제 당사 리스크 21건을 확인했다. 본문 밖의 제목으로
당사 부정 분류가 된 18편과 같은 기사의 중복 DB 기록 1건을 확인했다.
원문 본문을 검증하지 못한 2건은 기존 분류를 유지한다.

## 원인과 변경

기존 추출기는 정규식으로 찾은 본문과 페이지 전체 문단 중 가장 긴 값을
선택했다. 넓은 article-body 영역과 사이드바의 article 태그도 본문으로
선택될 수 있었다. 이 과정에서 관련기사 제목과 공유 버튼 JavaScript가
부정 사건의 근거 문장에 포함됐다.

- 표준 HTMLParser로 DOM을 구성하고, 정확한 본문 ID/itemprop을 클래스
  영역보다 먼저 선택한다. 일반 article은 마지막 본문 후보로만 사용한다.
- 관련기사, 자동 기사 목록, 광고, 기자정보, 공유 UI, 스크립트, 사진 설명,
  사이드바와 푸터는 제외한다. 전체 페이지 문단 fallback은 제거했다.
- 일반 수집, 민감 기사 보강, 공식 RSS 본문, 운영관리 원문 재확인이 같은
  추출 규칙을 사용한다. 원문 부족은 부정 또는 정상으로 확정하지 않는다.
- 문단 경계를 보존해 떨어져 있는 당사 이름과 타사 위험 사건을 한 문장으로
  합치지 않는다.
- 본문 범위 버전, 본문 SHA-256, 확인 URL을 기록하고, 분류 버전을 올려
  이전 오염 분류 캐시가 재사용되지 않도록 했다. 본문 변경도 캐시를 무효화한다.
- DB 경보 경로는 생성 요약을 원문 description으로 사용하지 않는다.
  확인되지 않은 저장 본문은 실제 기사 원문으로 다시 검증한다. 제목만으로
  당사 사건이 명확한 경우와 검증된 본문은 추가 다운로드 없이 사용할 수 있다.

## 검증과 정정

수집·분류·감시·언론사 정보·보고서·대시보드 관련 회귀 401개를 통과했다.
원문 밖 오경보, 중첩 DOM, RSS 관련기사, 실제 본문 부정, 문단 분리,
DB 요약 오염, 본문 근거만 있는 경보를 별도로 검증했다.

최근 사례 정정은 실제 원문에 당사가 없음을 확인한 기록으로 제한한다.
수동 수정은 보호하며, 반영 직전 DB 동시 변경을 검사한다. 변경 전 DB와
제안 값을 비공개 점검 이력에 남기고, 반영 후 분류와 캐시를 재조회한다.
이미 발송한 Slack 기록을 삭제하거나 보고서를 재발송하지 않는다.
