# 다음 기사 언론사 판별 보완

## 확인된 원인

- 대상: https://v.daum.net/v/20260909165149886
- 제공사 메타데이터는 `Daum | 아시아경제`, 본문 하단은 `Copyright © 아시아경제`로 일치한다.
- 이전 판별기는 포털 주소를 파싱 전에 제외했다. 또한 저작권 문장이 일반 `p`라서 footer/copyright 영역 탐지에 포함되지 않았다.
- DB에는 직접 다음 주소가 아니라 구글 RSS 중계 주소로 저장된 미확인 기사 257456이 있다. 별도의 아시아경제 원문 수집본은 이미 정상 분류되어 있다.

## 변경 범위

- 정확한 다음 기사 주소에서만 제공사 메타데이터와 본문 밖 저작권 문단을 교차 확인한다.
- 사진, 인용문, 본문, 추천 기사, 포털 회사명은 언론사 증거로 사용하지 않는다.
- 본문 확보 때 받은 HTML을 재사용한다. 별도 보강은 기존 브리핑 완료 후 제한된 작업에서 실행한다.
- 다음 페이지의 추천 기사 링크를 현재 기사 원문으로 잘못 추출하지 않는다.
- 증거가 확인된 기사별 언론사명은 재수집으로 사라지지 않게 DB에서 보존한다. 수동 수정은 우선한다.
- 분류, 논조, 경보, 기존 발송 기록은 수정하지 않는다.

## 범위 제한

- 구글 RSS 중계 주소만 있고 실제 기사 주소가 없는 항목을 자동으로 전부 복원하는 기능은 이번 변경에 포함하지 않는다.
- 대상 기사에는 사용자가 제공한 다음 주소와 제목을 확인해 기사별 증거를 저장한다. 다음 도메인 전체를 아시아경제에 매핑하지 않는다.
- 기존 발송된 정적 HTML 보고서는 별도 재생성하지 않는다.

## 검증

- `tests/test_publisher_identity.py`, `tests/test_media_byline.py`: 정상 판별, 상충 증거, 사진/인용 제외, 기존 판별 보존, 추가 본문 요청 없음.
- `tests/daum_publisher_regression.sql`: 재수집 보존, 증거 부족 거부, 수동 수정 우선, 보강 큐 비공개. 테스트 자료는 rollback.
